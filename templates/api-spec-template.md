## 텍스트 API 예제 계약

`text` 누락·빈 문자열·공백만 있는 문자열·잘못된 타입은 모두 422로 처리합니다. Pydantic v2에서 `StringConstraints(strip_whitespace=True, min_length=1)`와 strict 문자열을 사용합니다. 오류 `detail`은 FastAPI 기본 검증 오류 배열이며 고정 문자열 응답으로 가정하지 않습니다. 정상은 200입니다. 외부 제공자의 타임아웃·연결 실패·제공자의 요청 거부·사용 불가능한 응답은 502로 통일합니다. 서비스 어댑터는 SDK별 제공자 오류와 응답 해석·검증 실패를 `ProviderError`로 변환하고, 라우터는 `TimeoutError`, `ConnectionError`, `ProviderError`를 502로 변환합니다. 예상하지 못한 애플리케이션 버그(예: `RuntimeError`)는 500이며 제공자 실패와 구분합니다. 모든 예외를 502로 덮지 않습니다. 502 detail은 `Summary provider unavailable`, 500은 기본 `Internal Server Error`이며 원래 예외·키·내부 설정은 노출하지 않습니다.
