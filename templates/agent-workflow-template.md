## 제한된 재시도와 실패 종료

| 항목 | 설계 |
| --- | --- |
| 상태 필드 | attempt / max_attempts / status / error / completed_actions |
| 시도 정의 | 최초 실행을 포함한 전체 횟수; 실행 직전 증가 |
| 한도·시간 제한 | 프로젝트에서 확정; 한도 도달 시 실패 종료·사용자 안내 |
| 재시도 대상 | 일시 오류만; 권한·입력 오류는 수정 또는 사용자 확인 |
| 외부 작업 | 작업 ID·상태(pending/succeeded/unknown)·결과 식별자 기록 |
| 중복 방지 | succeeded는 재실행 안 함; unknown은 조회로 확인 전 재실행 안 함 |
| 재개 | 저장된 상태를 확인하고 미완료 안전 단계부터 진행 |

상태 저장과 외부 작업은 원자적이지 않을 수 있습니다. 제공 도구의 멱등성 키를 사용하거나 작업 ID로 조회합니다. 확인할 수 없으면 중단하고 사용자에게 결과 불확실을 알립니다. 발송은 승인된 대상·내용·범위에 한하며 기본 검증은 모의 도구나 초안으로 합니다.
