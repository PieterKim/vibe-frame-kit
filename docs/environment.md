# 공통 환경과 도구

| 구분 | 공통 필수 | 실습별 선택 | 점검 |
| --- | --- | --- | --- |
| Codex | 강사가 선정한 클라이언트·인증·프로젝트 파일 읽기/편집/명령 실행·Skill 발견 | 웹·추가 도구 | 클라이언트 버전과 Skill 목록을 기록; 네트워크/쓰기 허용 범위 확인 |
| 설치 | Git, Python 3.11+ | PowerShell 또는 Bash 래퍼 | `git --version`, `python --version`, `python scripts/check-environment.py` |
| Python | Python 기반 실습에서 가상환경·패키지 잠금 파일 | FastAPI·Pydantic·AI SDK·벡터 저장소 | 선택 실습에 필요한 의존성만 설치; 실제 검증 후 버전 고정 |
| Node.js | 프론트엔드 실습을 선택할 때만 | npm·프레임워크 | `node --version`, `npm --version`; lockfile로 재현 |
| MCP | 공통 필수 서버는 아직 미정 | Gmail 등 선택한 서버 | 도구 목록·입출력 스키마·인증 범위·테스트 계정 확인 |

## 강사 결정 기록

| 미정 항목 | 담당 | 결정 근거·시점 | 현재 대안 |
| --- | --- | --- | --- |
| Codex 클라이언트·모델 | 강사 | 수업 전 접근성·비용·동일 과제 확인 | 로컬 구조·모의 검증 |
| 공통 MCP와 권한 | 강사 | 해당 실습 전 최소 권한과 사용 가능한 도구 확인 | 모의 도구·초안 |
| OS·Python/Node/SDK 버전 | 강사 | 대상 OS 설치·대표 실습 검증 후 고정 | 실행 환경은 검증 보고서에 기록 |

위 설치기 Python 최소 버전은 도구 구현 요건이며 수업 전체 버전 확정이 아닙니다. 비밀값은 검사·로그·보고서에 출력하지 않습니다. 키가 필요한 실습은 설정 여부만 확인합니다. 실제 발송·유료 호출은 별도 승인된 실습에서만 합니다.

## 설치본에서 환경 점검 실행

프로젝트 범위 설치에는 `scripts/check-environment.py`가 포함됩니다. 설치된 프로젝트 루트에서 `python scripts/check-environment.py`를 실행합니다. 선택적 전역 설치는 `$CODEX_HOME/vibe-frame-kit/`(미설정 시 `~/.codex/vibe-frame-kit/`)에 같은 스크립트를 설치합니다. 그 자료 폴더를 현재 폴더로 열고 같은 명령을 실행하면 됩니다. 원본 Kit 없이도 실행할 수 있습니다. 설치기와 회귀 검사기는 설치하지 않으며 원본 Kit 루트에서 실행합니다.

점검기는 표준 라이브러리만 사용하며 실행 파일의 존재 여부와 OS/Python 버전만 출력합니다. 인증 파일이나 환경 변수의 값을 읽거나 외부 명령·네트워크를 실행하지 않습니다.
