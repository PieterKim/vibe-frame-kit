# 후반 선택 실습 체크리스트

MVP가 해당 기능을 필요로 할 때만 사용합니다. 첫 실습에 모든 항목을 강제하지 않습니다. 결과는 Agent 설계서와 테스트 시나리오에 연결합니다.

## RAG

- 문서 ID·출처·페이지·접근 권한과 metadata를 보존합니다.
- chunk 크기·중첩·embedding 모델·차원·검색 개수를 선택한 이유와 함께 기록합니다. 변경 시 인덱스 재생성 여부를 확인합니다.
- 고정 질문에 대해 검색 문서와 답변 근거를 각각 평가합니다. 검색 성공을 답변 정확성으로 간주하지 않습니다.
- 검색 결과 없음·상충 자료·권한 없는 자료에서는 근거 부족을 안내하고 추측하지 않습니다. 출처가 실제 문서 구간을 가리키는지 확인합니다.

## LangGraph

- State 필드·타입·초기값·각 Node의 읽기/쓰기를 정의합니다. 병렬 합치기는 Reducer와 중복 방지를 확인합니다.
- Checkpointer 저장 범위와 thread_id 분리를 확인하여 다른 사용자·작업 상태가 섞이지 않게 합니다.
- 중단 위치·사람의 검토·재개 입력·상태를 기록하고 최대 시도·실패 종료를 검증합니다.
- 중단 후 재개에서 외부 작업이 다시 실행될 수 있음을 고려하고 완료 작업 ID를 조회합니다.

## MCP / Gmail

- 실제 연결에서 도구 목록과 스키마를 읽습니다. 도구명·파라미터·인증 범위를 추측하지 않습니다.
- 조회·초안·발송을 구분하고 필요한 최소 권한을 사용합니다. 기본 테스트는 모의 도구 또는 승인된 테스트 계정의 초안입니다.
- 발송은 명시적으로 승인된 대상·내용·범위에서만 실행합니다. 키·본문 개인정보를 로그에 남기지 않습니다.
- 작업 ID·외부 결과 ID·성공/실패/불확실을 저장합니다. 시간 초과 후에는 조회부터 하며 중복 발송하지 않습니다.
- 정상·권한 오류·타임아웃·재개·중복 요청을 검증합니다. 실제 발송을 안 했으면 미실행으로 기록합니다.
